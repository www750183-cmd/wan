# 多平台视频收录与互动助手

抖音 / 小红书的**视频抓取 + 自动点赞 + AI 自动评论 + 运行日志**。Chrome MV3 扩展，**无构建步骤**，这个目录就是扩展本体。

---

## 一、固定流程

一条作品进来，走的顺序永远是这四步：

```
① 抓取        打开作品页，一次拿全：标题、链接、点赞数、评论数、收藏数、评论区全部评论
② 点赞        已是点赞态就跳过；状态读不出来也跳过（不猜）
③ 评论        把「视频文案 + 评论区」喂给模型 → 生成评论 → 五道校验 → 发布
④ 日志        写一条记录，含你要求的 8 个字段
```

**日志字段（固定顺序）**：视频标题 · 视频链接 · 点赞数 · 评论数 · 收藏数 · 评论区关注点 · 评论内容 · 执行结果

**执行结果**长这样：`点赞✅评论✅`　全部成功
`点赞✅评论⚠`　评论已提交但没能确证（建议人工看一眼）
`点赞⏭评论✅`　本来就点过赞了，跳过
`点赞❌评论❌`　失败，日志的「说明」列会写原因

标记含义：`✅`成功　`❌`失败　`⏭`跳过（已经是目标状态）　`⚠`提交了但未能确证

**试跑也显示 ✅**——试跑验证的是「这条路走不走得通」，走通了就是 ✅，状态列会另外标「试跑」。

## 二、能力边界

| 平台 | 抓取 | 点赞 | 评论 |
|---|---|---|---|
| **抖音** | ✅ | ✅ | ✅ |
| **小红书** | ✅ | ✅ | ✅ |
| **视频号** | ⚠️ 仅自己账号的作品列表 | ❌ | ❌ |

**视频号为什么不行**：视频号的内容消费在微信 App 内，网页端 `channels.weixin.qq.com` 只是创作者后台，没有浏览他人作品和互动的入口。这是产品形态决定的，不是实现难度。

**关于"抓取"的边界**：浏览器能拿到的是**页面文案、话题标签、评论区全文**。**视频画面里的内容**（口播、画面里的字）拿不到，除非另接语音转写/OCR。所以"评论区关注点"是模型读文案+评论得出的。

## 三、安装与使用

```
chrome://extensions/ → 开发者模式 → 加载已解压的扩展程序 → 选本目录
```

**整个控制台只有三样东西**（按页面从上到下）：

```
        右上角：[大模型设置] [高级] [停止]      ← 平时不用点

    ┌───────────────────────────────────────────┐
    │      粘贴视频链接，点开始就行              │
    │  [ 粘贴视频链接/分享文案/关键词 ] [ 开始 ]  │   ← 就这一件事
    │  ☑ 先试跑一遍（只生成不执行）              │
    │  将处理 1 个视频（试跑，不会真的点赞评论）  │
    └───────────────────────────────────────────┘

    运行日志
    [导出 CSV] [导出 Markdown] [导出 JSON] [清空日志]
    ┌────────┬──────┬──────┬────┬────┬────┬──────┬──────┬──────┐
    │ 时间｜视频标题｜视频链接｜点赞数｜评论数｜收藏数｜关注点｜评论｜结果 │
    └────────┴──────┴──────┴────┴────┴────┴──────┴──────┴──────┘
```

**第一次用只做一件事**：**大模型设置会自动展开**（因为还没配 Key），把 API Key 填进去，点保存。配好之后它会自动收起，永远不用再管。

右上角两个按钮的底色就是状态：**灰色 = 面板正开着，透明 = 关着**。

然后就是**粘链接 → 点开始**。

- 想先看效果：保持「先试跑一遍」勾选，它会把流程完整走一遍但不真的点赞评论
- 想真跑：取消勾选，点开始（会弹一次确认）
- 评论人设、意图、字数、禁词、限速、间隔、每轮条数——**全部有内置默认值，不需要填**

**右上角「高级」里有什么**（正常使用完全不用打开）：执行内容开关、评论写法、速度与风控、网页元素校准。全部有默认值。

## 三点五、分发前改这一个文件

打包发给别人之前，只改 `src/config.js`：

```js
export const DIST = {
  defaultApiBase: 'https://www.manbouapi.com/v1',  // 默认服务地址
  defaultModel: 'deepseek-v4.1-flash-0910',        // 默认模型名
  inviteUrl: '',                                   // ← 填你的邀请链接
  inviteText: '还没有 API Key？点这里获取',
  inviteNote: '',
};
```

- **`inviteUrl` 填上之后**：大模型设置面板里会出现一行「还没有 API Key？点这里获取」指向你的链接。
- **留空（默认）**：界面里**不出现任何服务商的名字或链接**——包括输入框的提示文字。这是刻意的：不必替任何服务商免费打广告。
- `defaultApiBase` 是用户不填服务地址时用的默认值。如果你有自己的中转，把它改成你的地址，客户开箱即用。

界面里有专门的测试守着这条：**任何 placeholder 里都不允许出现非平台的 URL**，也不允许出现服务商域名。

## 四、评论是怎么生成的

模型收到的输入：标题、正文、话题标签、作者、点赞/评论数、**评论区已有的全部评论**，加上你配置的身份和意图。所以它能"看人下菜"：

- 评论区在**问价** → 用"自己也买过类似的"同好口吻含蓄带出渠道
- 评论区在**夸细节** → 接住那个细节具体地夸
- 评论区在**求教程** → 顺着说自己也想要一份

**实测例子**（书法作品 + 评论区问价）：

> 评论区关注点：在问价、问纸的来路、求教程，还有人想拜师。
> **生成评论：「去年在老师那儿收过一把差不多的，半生熟写小楷确实顺手，这两方印配得也讲究。」**

同时会生成另外 2 条候选，日志里能看到最终用了哪条。

### 五道硬性校验（任一不过就换下一条，全不过就不发）

| 校验 | 默认 |
|---|---|
| 长度 | 8–45 字（太短像水军，太长像广告） |
| 禁词 | 链接/私信/微信/加我/购买/淘宝/拼多多/优惠/代购… |
| 链接与 @ | 一律拒绝 |
| **与评论区重复** | 二元组相似度 ≥ 0.6 就判重（防"抄一条改两个字"） |
| 句式 | 提示词层面禁止"求链接""怎么买""多少钱出吗" |

## 五、安全机制（默认全开）

| 机制 | 默认 | 说明 |
|---|---|---|
| 演练模式 | **开** | 走完整流程但不真跑 |
| 随机间隔 | 20–45 秒/条 | 固定间隔最容易被风控识别 |
| 历史去重 | 开 | 按 `平台:作品ID:flow` 记录，处理过的自动跳过 |
| 每日上限 | 200 | 到量自动停 |
| 连续失败熔断 | 5 次 | 连续失败 = 选择器坏了或掉登录，立即停并说明原因 |
| 未登录中止 | 内置 | 检测到登录标记立刻中止整批 |
| 状态二次确认 | 内置 | 已是目标状态就跳过；**状态读不出来也跳过，不猜** |
| 发布后校验 | 内置 | 确认评论真的写进了输入框才提交；提交后无法确证标「⚠」而不是报成功 |

**不做的事**：不伪造请求头、不改浏览器指纹、不绕验证码。

## 六、权限说明

所有操作都在**平台页面自身的上下文**里完成（开真实页面 → 等渲染 → 在页面里操作），所以：

- **不需要 `cookies` 权限**：页面自带登录态
- **不需要 `debugger` 权限**：用 DOM 操作，不接管调试协议
- 只需要 `storage` / `tabs` / `scripting` / `downloads` / `notifications`
- `host_permissions` 只声明抖音、小红书、视频号的域名，不是 `<all_urls>`

## 七、选择器会失效，所以「能自己修」做进了产品

平台改版必然让选择器失效。展开「高级 → 网页元素校准」：

1. 选平台，填一个真实作品页 URL，点 **打开页面**
2. 点 **自检当前页**：直接给结论（能不能开跑）。**评论收起的平台（抖音）会自动点开评论区再测**，否则测的是收起状态、结论没意义
3. 红点的项：选中 → 点 **开始拾取** → 到刚打开的页面上点你要的元素（点击被拦截，不会触发页面自身功能）→ 回来点 **保存**
4. 再点 **自检当前页** 确认变绿

**全程不用改代码。**

自检**不会骗你**，它区分四种语义——**只有红点才需要处理**：

| 点 | 含义 |
|---|---|
| 🟢 绿 | 命中，正常 |
| 🔴 红 | **真的会影响运行，需要修** |
| ⚪ 灰 | 可选项没抓到（作者名、标签、评论点赞数等），只影响日志里那几列，**不影响点赞评论** |
| ⚪ 浅点 | `collectLinks` 只在列表页用（详情页不需要）；`loginFlag` 是反向语义（绿=已登录） |

### 还有一层自动兜底

选择器**没命中时不会直接失败**，而是在页面上自动找：

| 找不到 | 会自动找 |
|---|---|
| 评论输入框 | 页面上可见的 `contenteditable` / `textarea`，优先带「说点什么」提示的 |
| 评论提交按钮 | 输入框附近文字是「发送/发布/评论」的按钮 |
| 评论区 | class 里含 `comment` 且重复出现的一组元素 |
| 视频标题 | `og:title` / 文档标题（自动去掉「- 抖音」这类后缀） |
| 点赞数/评论数/收藏数 | 按钮自己或兄弟节点里的数字；再兜底到页面文本里的「xx 点赞」 |

所以平台小改版通常不用管；真失效了自检会告诉你，拾取器点一下就好。

## 九、已知限制

- **必须开着 Chrome**：任务跑在浏览器里，页面要真实打开。最小化可以，别关窗口。
- **慢是设计**：每条作品要开页面、抓评论、调一次模型（约 30 秒），加上 20–45 秒间隔，跑 3 条大约 3 分钟。这是风控安全的代价。
- **视频号只能收录自己账号**：见第一节。
- **视频画面内容拿不到**：见第一节。
- **后台标签页可能被节流**：默认后台标签页。某些平台渲染不出来时，把「页面打开方式」改成**小窗渲染**。

## 十、合规提醒

- 本工具用于操作**你自己的账号**。批量点赞评论可能违反平台用户协议，风险由使用者承担。
- 建议：先用小号验证、每天少量、不要用于刷量或商业水军。
- 插件不采集、不上传任何数据到第三方；所有记录都在本机，导出文件落在你的下载目录。
