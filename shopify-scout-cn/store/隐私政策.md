# 隐私政策 · 选品侦探（Shopify 店铺侦察兵）

**最后更新：2026-09-22**
**适用版本：1.0.0 及以后**

---

## 一句话说明

**本扩展不收集、不存储、不传输你的任何数据。** 所有分析都在你自己的电脑上完成。

---

## 我们收集什么

**什么都不收集。**

本扩展没有服务器，没有后端接口，代码里不存在任何指向第三方的网络请求。
你可以断网使用它，功能完全不受影响 —— 这是最直接的自证方式。

具体到每一项：

| 常见收集项 | 本扩展的做法 |
|---|---|
| 浏览历史 | **不记录** |
| 你打开的网址 | **不记录**。只在你主动点击图标的那一刻，读取当前这一个标签页 |
| 你没点开的标签页 | **完全不读取** |
| 页面内容 | 在本机读取、在本机分析，**不外传、不存储到任何远端** |
| Cookie | 只读取 Cookie 的**名字**，不读取任何值（值里可能有购物车令牌或登录凭据） |
| 账号与登录信息 | 不获取，不要求登录 |
| 位置信息 | 不获取 |
| 设备标识 / 指纹 | 不生成、不采集 |

---

## 数据存在哪里

全部存在你自己的浏览器里，用 `chrome.storage` 保存：

- 你的扫描设置
- 你收藏的店铺
- 扫描历史
- 「店铺变化」功能需要的对比记录（为了一家店的变化能算出来，需要记住它上次长什么样）

**这些数据不会离开你的电脑。** 卸载扩展即全部清除；也可以在扩展界面里手动清空。

---

## 本扩展会读取什么，为什么

当你**主动点击工具栏图标**时，扩展会读取当前标签页上**公开可见**的以下内容，
用于生成分析结果：

- 店铺页面上公开的主题信息（Shopify 会在页面里声明自己的主题名与版本）
- 页面上加载的脚本与样式地址（用于识别店铺装了哪些第三方应用和追踪像素）
- 页面上的 meta 标签与可见文本

这是分析一个店铺所必需的最小信息。读取结果只在你的浏览器里参与计算并显示给你，
**不发送到任何地方**。

扩展刻意排除了几类会暴露「你在看哪一页」的链接（`rel=canonical`、`next`、`prev`、
`alternate`、`shortlink`、`amphtml`），即便在本地也不会采集它们。

---

## 权限说明

| 权限 | 用途 |
|---|---|
| `activeTab` | 只在你点击图标时，读取**当前这一个**标签页。刻意用它代替 `<all_urls>`，避免申请全网访问 |
| `scripting` | 向当前标签页注入只读的采集脚本，不修改页面内容 |
| `storage` | 在本机保存设置、收藏与历史 |
| `sidePanel` | 显示右侧操作面板 |
| `downloads` | 把结果导出成 CSV / JSON 文件保存到本地 |

本扩展**没有申请任何网站访问权限**（无 `host_permissions`）。

---

## 关于「店铺变化」功能的说明

「店铺变化」展示的是从店铺**公开可读信息**重建的成交线索，**不是订单数据**。

Shopify 平台不公开订单接口，任何浏览器扩展都无法获取他人店铺的真实订单。
本扩展给出的「卖光了 / 补货了 / 上新了」等标记来自你自己两次扫描之间的状态对比，
界面中已明确标注每一条的确定程度。

## 第三方

- 本扩展**不集成**任何第三方分析、广告或统计 SDK
- 本扩展**不向任何第三方出售或转让**任何数据（因为没有数据可转让）
- 本扩展加载的代码**全部包含在安装包里**，不存在运行时下载远程代码的行为

---

## 儿童隐私

本扩展不面向儿童，也不收集任何人的数据。

---

## 政策变更

如果未来版本改变了数据处理方式，我们会在此页面更新，并在扩展的版本说明中明确告知。
在任何情况下，都不会在未告知的情况下开始收集数据。
