# 免费大模型额度雷达 · 最简版

从上游拉取国内大模型厂商的**免费额度**信息，生成一份可直接阅读的清单。

## 怎么用

双击 `run.cmd`，或者在命令行里跑：

```bash
node sync.mjs
```

跑完得到两个文件：

| 文件 | 用途 |
|---|---|
| `免费额度清单.md` | **给人看的**，按免费类型分组，含门槛/入口/Base URL |
| `data/offers.json` | **给程序看的**，结构化数据，后续做插件用这个 |

## 它做什么

1. 拉上游 [DaBinBinah/free-LLM](https://github.com/DaBinBinah/free-LLM)（MIT）的两个 JSON
2. 把上游原始数据归档到 `data/upstream/YYYY-MM-DD/`（防上游停更或删库）
3. 归一化成 `data/offers.json`
4. 渲染成 `免费额度清单.md`

## 它不做什么（有意为之）

- **不爬各厂商官网** —— 上游已经做完了这件事，重复造轮子没意义
- **不查余额** —— 那需要你自己的 API Key，属于插件层的功能
- **不调任何大模型** —— 所以**运行成本是 ¥0**

## 关于数据可信度

**上游是人工维护的，不是每天更新的。** 脚本会如实标注新鲜度，不粉饰：

| 标记 | 含义 |
|---|---|
| 🟢 fresh | 7 天内复核过 |
| 🟡 aging | 8~14 天 |
| 🔴 stale | 超过 14 天，**额度可能已经变了** |

当前实测 17 家全部是 🔴 stale。所以：

> **照着清单去注册前，先点开「领取入口」确认一下额度还在不在。**

额度数字一律**照抄上游原文**，脚本不做任何改写或推算。

## 关于网络

Node 的 `fetch` 默认不读系统代理，而代理通常配在注册表里。脚本启动时会自动检测系统代理并改走代理，不需要手动设置。

如果检测失败，可以手动指定（把端口换成你自己的）：

```bash
HTTPS_PROXY=http://127.0.0.1:7890 node sync.mjs
```

## 环境要求

- Node.js ≥ 18（实测 v24 可用）
- **零依赖**，不需要 `npm install`
